🔧 MANUAL METHOD (If script doesn't work)
───────────────────────────────────────────────────────────────────────────

STEP 1: Create GitHub Repo (1 min)
   1. Go to: https://github.com/new
   2. Name: rupee-value-tracker
   3. Visibility: Public
   4. Click "Create"
   5. Copy the URL shown

STEP 2: Configure Git (30 sec)
   git config --global user.name "Your Name"
   git config --global user.email "your@email.com"

STEP 3: Add Remote (30 sec)
   git remote add origin https://github.com/YOUR_USERNAME/rupee-value-tracker.git

STEP 4: Push Code (1 min)
   git branch -M main
   git push -u origin main

STEP 5: Enable GitHub Pages (1 min)
   1. Go to repository Settings
   2. Click "Pages"
   3. Source: "Deploy from a branch"
   4. Branch: "main", Folder: "/ (root)"
   5. Click Save
   6. Wait 1-2 minutes
