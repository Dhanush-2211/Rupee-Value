## Deployment

### GitHub Pages (Easiest)
This website is hosted on GitHub Pages and is publicly accessible at:

```
https://YOUR_USERNAME.github.io/rupee-value-tracker
```

To deploy your own version:

1. Create a GitHub account at https://github.com
2. Create a new public repository named `rupee-value-tracker`
3. Clone or push this code to your repository
4. Enable GitHub Pages in Settings → Pages (source: main branch, root folder)
5. Your site will be live in 1-2 minutes!

### Alternative Hosting Options

- **Netlify** - https://netlify.com (drag & drop deployment)
- **Vercel** - https://vercel.com (automated deployments)
- **Custom Server** - Deploy on any web server with HTTP support

## Local Development

To test the website locally:

1. Open `index.html` directly in your browser, or
2. Use a local server:
   ```bash
   python -m http.server 8000
   # OR
   python3 -m http.server 8000
   ```
3. Visit: http://localhost:8000
